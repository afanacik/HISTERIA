📝 Шаблоны ВК
Кнопка на vk.com / vk.ru: группы, переменные, вставка в диалог
Сейчас сохранено
—
Круглая кнопка 📝 появляется поверх страницы ВК — её можно перетащить в любое место. Внутри панели: вкладки-группы, кнопка «✎» для управления группами, «⚙» — личные данные для переменных ({Ваше имя}, {Название сообщества} и т.д.), а также экспорт и импорт шаблонов.
Переносишь данные со старого расширения «VK Шаблоны»? Экспортируй там файл vk-templates.json и загрузи его кнопкой «Импорт» внизу этого окна.
🕶 Невидимка
Модуль невидимки на ВК (как в Kate Mobile)
Не помечать прочитанным
Собеседник не видит, что сообщение прочитано
Скрывать онлайн
Не показывать «online», остаётся «был(а) в сети»
Скрывать «печатает…»
Собеседник не видит, что ты набираешь сообщение
Активная вкладка
На самой странице ВК ничего не рисуется, управление только отсюда. Переключатели действуют сразу на всех открытых вкладках ВК, перезагружать не нужно. Скрытие онлайна работает только пока ты сидишь в веб-версии; мобильное приложение всё равно покажет онлайн.
Тонкая настройка «онлайна»
Если ВК поменяет протокол и онлайн снова начнёт гореть, сюда вставляется новый список признаков. Сохраняется по Enter или при уходе из поля.
Диагностика запросов
Вести журнал запросов ВК-клиента для подбора признаков
Включи, посиди пару минут в диалогах ВК, потом скопируй журнал и пришли его: по нему подбираются точные признаки. В обычной работе держи выключенным.
