# Кит — 5 расширений в одном  ·  v2.6.1

Объединены: **ГрамФикс v3.0**, **VK Шаблоны v2.0**, **VK Невидимка v1.0**, **VK st fix v1.1**, **Мой сигнал для ChatGPT v2.2**.
Один манифест, один попап с вкладками, каждый модуль включается и выключается отдельно.

## Установка

1. Распаковать папку `kit` в постоянное место (не в «Загрузки» — при удалении папки расширение отвалится).
2. `chrome://extensions` → включить «Режим разработчика» → **Загрузить распакованное расширение** → выбрать папку `kit`.
3. Старые четыре расширения удалить (иначе на ВК будут две кнопки шаблонов и две плашки невидимки).

## Обновление

1. На всякий случай сделать бэкап: попап, внизу **⬇ Экспорт** (шаблоны и файлы; API-ключ в бэкап не попадает).
2. Заменить файлы **в той же папке** `kit`, из которой расширение установлено.
3. `chrome://extensions`, на карточке «Кит» нажать круглую стрелку ↻ (обновить).
4. Обновить открытые вкладки (F5).

Не удалять расширение и не загружать его из другой папки: у распакованного расширения ID зависит от пути к папке, и в новой папке не будет ни ключа, ни шаблонов.

## Перенос данных со старых расширений

У нового расширения свой ID, поэтому хранилище чистое:

- **Шаблоны.** В старом расширении: кнопка 📝 → ⚙ → «Экспорт» → файл `vk-templates.json`.
  В новом: попап → внизу **⬆ Импорт** → выбрать этот файл. Группы, шаблоны и личные данные подхватятся.
- **API-ключ ГрамФикс.** Вставить заново на вкладке «Текст» (в бэкап ключ намеренно не выгружается).
- **Настройки st fix.** Заданы по умолчанию: `st*-54.vk.ru → st1-53.vk.ru`.

| ✨ Текст | Меню правки при печати: исправить / сформулировать / перевести. Горячие клавиши `Ctrl+Shift+F` / `S` / `E`, опционально — автоправка при уходе из поля | все сайты |

## v2.6.1 — исправления безопасности

Проверка кода нашла три проблемы. Каждая подтверждена атакой в тестовом браузере на v2.6.0 и закрыта в v2.6.1:

- **ГрамФикс вставлял ответ ИИ в страницу как HTML.** Если в тексте был спрятан приказ для модели («верни `<img onerror=…>`»), её ответ запускал скрипт на этом сайте. Теперь список правок и тексты ошибок выводятся только как текст.
- **Сайт мог сам запустить автоисправление.** При включённой автоправке страница могла вписать свой текст в поле и сымитировать печать: текст уходил в AI за твой счёт. Теперь автоправка срабатывает только после настоящих нажатий клавиш (`isTrusted`).
- **Импорт бэкапа принимал любые ключи хранилища**, в том числе `apiKey` и `openaiApiKey`. Подсунутый файл мог подменить ключ на чужой, и тексты уходили бы в чужой аккаунт. Теперь импорт берёт только известные настройки нужного типа, а ключи API не берёт никогда. Также проверяются хост st-fix и звуковой файл.
- Шаблоны ВК: идентификаторы и картинки вложений перед вставкой в панель экранируются и проверяются (защита от испорченного бэкапа).

## Безопасность: что важно знать

- **Доступа к компьютеру у расширения нет.** Оно не запускает программы, не читает файлы с диска и не открывает портов. Связи с программами на ПК (`nativeMessaging`) нет. Код не скачивается из интернета, а без вашего ведома не обновляется.
- **Зато у него широкие права в браузере:** «читать и изменять данные на всех сайтах» (это нужно ГрамФиксу). Поэтому главное правило: **не заменяй файлы в папке `kit` кодом из непроверенных источников.** Расширение с такими правами может прочитать всё, что ты видишь и вводишь на сайтах.
- **Сеть:** обращается только к `api.anthropic.com` / `api.openai.com` (ГрамФикс, только по твоему действию или при включённой автоправке). Сигнал ChatGPT в сеть не ходит.
- **API-ключи** лежат в профиле Chrome незашифрованными (как у любых расширений). Поставь лимит расходов на ключ в консоли Anthropic/OpenAI; если ключ мог утечь — отзови и создай новый.
- **ГрамФикс отправляет текст поля в AI-сервис.** Не жми «Исправить» в полях с паролями, номерами карт и паспортными данными. Поля `type=password` он не трогает.
- **«Разрешить доступ к URL файлов»** на `chrome://extensions` держи выключенным: расширению не нужен доступ к файлам на диске.

## v2.6.0

- Новый модуль **🔔 Сигнал** (бывшее отдельное расширение «Мой сигнал для ChatGPT»). Когда ChatGPT закончил отвечать — звук; если ты в это время на другой вкладке, значок вкладки ChatGPT становится зелёной галочкой, пока её не откроешь. По желанию — уведомление Windows с переходом на вкладку.
- Конец ответа определяется тремя способами: окончание сетевого потока ответа (`content/gpt-hook.js`, MAIN-мир, перехват `fetch` без чтения текста), кнопка «Стоп» и, как резерв, «страница перестала меняться после отправки». Ручной «Стоп» сигнала не даёт.
- Звук играет в offscreen-документе (`gpt-offscreen.html`); если он недоступен — прямо на странице ChatGPT, а «Проверить звук» — прямо в попапе.
- Вкладка «Сигнал»: выключатель модуля (красная точка, когда выключен), «только в фоне», «отмечать вкладку», уведомление, выбор звука, свой файл (до 3 МБ), громкость, статистика (сегодня, всего, сколько ждали, самый долгий ответ), журнал событий с копированием. Если открыть попап на вкладке ChatGPT, сразу открывается «Сигнал».
- После установки или ↻ модуль сам подключается к уже открытым вкладкам ChatGPT — F5 не нужен.
- Экспорт/импорт включает настройки сигнала, свой звуковой файл и статистику.
- Новые разрешения: `offscreen` (играть звук в фоне), `notifications` (уведомление).
- **Старое расширение «Мой сигнал для ChatGPT» удалить**, иначе сигнал будет звучать дважды.

## v2.5.0

- ГрамФикс поддерживает Anthropic Claude и OpenAI ChatGPT: переключатель провайдера на вкладке «Текст», отдельное поле API-ключа и отдельный выбор модели для каждого сервиса. Claude остаётся выбранным у существующих пользователей.
- OpenAI: GPT-4.1 mini (по умолчанию), GPT-5 mini и GPT-4.1 nano. Запросы идут напрямую из service worker на `https://api.openai.com/v1/chat/completions` с `Authorization: Bearer ...`, JSON-режимом и `store:false`. Anthropic продолжает работать как раньше.
- Старый ключ `apiKey` сохранён без миграции и не перезаписывается OpenAI-ключом `openaiApiKey`; оба лежат в локальном хранилище. Ключи не включаются в экспорт, не передаются из content-script в запросах к фоновому скрипту.
- Кнопка исправления, диагностика и автоисправление учитывают выбранного провайдера и наличие его ключа. Экспорт/импорт сохраняет выбранные модели и сервис без секретных ключей.
- Важно: нужен ключ с `platform.openai.com/api-keys` с настроенной оплатой API. Подписка ChatGPT Plus не заменяет оплату OpenAI API.

## Что изменилось по сравнению с исходниками

- Единый попап с вкладками вместо четырёх разных интерфейсов; выключатель у каждого модуля.
- Невидимка получила мост между MAIN-миром и `chrome.storage`: состояние живёт в настройках расширения и применяется на всех открытых вкладках ВК сразу. Плашки на странице нет — вместо неё в попапе показывается статус активной вкладки и счётчик перехваченных отметок (читается из `data-ak-stealth-blocked`).
- st fix переведён со статического `rules.json` на динамические правила: номер битого шарда и рабочий хост меняются прямо в попапе, с проверкой на петлю перенаправления. В попапе видно, какое правило активно сейчас.
- Шаблоны включаются и выключаются на лету, без перезагрузки вкладки ВК.
- Общий экспорт/импорт всех данных (импорт понимает и старый формат `vk-templates.json`).
- ГрамФикс больше не подхватывает чужие ключи из `chrome.storage.local` (раньше слушал все изменения подряд).
- Значок ГрамФикса перетаскивается: зажать и потащить. Место запоминается (`gfPos` в `chrome.storage.local`) и действует на всех сайтах, значок перестаёт привязываться к полю. Вернуть привязку — кнопка «📍 Вернуть значок к полю ввода» в попапе. Перенос от клика отличается порогом в 4 px, так что дрожание руки по-прежнему считается кликом.
- Автоисправление после паузы в печати: на значке идёт обратный отсчёт (SVG-кольцо + цифра секунд), длительность паузы задаётся ползунком 1–15 с. Любое нажатие клавиши перезапускает отсчёт, клик по значку исправляет сразу, Esc отменяет до перехода в другое поле. Исправленный текст запоминается, чтобы отсчёт не пошёл по кругу и не ушёл лишний запрос к API.
- Реализовано автоисправление при уходе из поля: в ГрамФикс v2.0 переключатель «Автоисправление» был в попапе, но `content.js` его не читал — функция не работала. Теперь работает, по умолчанию выключена (тратит токены без спроса). Не срабатывает, если в поле ничего не печатали, короче 10 символов, или если текст успел смениться, пока шёл ответ API; фокус после правки возвращается туда, где был.
- Значок ГрамФикса теперь появляется и без API-ключа (раньше без ключа модуль молчал и выглядел сломанным), скрипт работает во вложенных фреймах (`all_frames`), а над узким полем меню встаёт сверху — у чат-композеров внизу экрана места под ним нет.
- В попапе есть диагностика вкладки по фреймам.
- Иконки перерисованы: PNG из `gramfix_v3/icons` оказались битыми (валидный заголовок, повреждённый поток данных).

## Кнопки у поля ввода

В меню у поля показывается только «Исправить» — список задаётся константой `MENU_MODES`
в начале `content/gramfix.js`. Чтобы вернуть остальные кнопки:
`const MENU_MODES = ['fix', 'rephrase', 'translate'];`.
Режимы, которых нет в меню, продолжают работать по горячим клавишам.

## Если значок ГрамФикса не появляется

Попап → вкладка «Текст» → **🔍 Диагностика активной вкладки**. Она проверяет три вещи:
задан ли API-ключ, включён ли модуль и загрузился ли скрипт в каждый фрейм страницы
(с числом найденных полей ввода). Значок не появится, если модуль выключен;
без ключа значок появится, но по клику скажет, что ключ нужен.

## Структура

```
kit/
├── manifest.json
├── background.js              service worker: Anthropic API + правила DNR
├── gpt-signal-bg.js           «Сигнал»: звук, уведомление, статистика, журнал (importScripts)
├── gpt-offscreen.html / .js   скрытый плеер сигнала
├── popup.html / popup.js      единый интерфейс
├── icons/
└── content/
    ├── gramfix.js             меню правки текста (все сайты)
    ├── vk-templates.js        шаблоны сообщений
    ├── vk-stealth.js          перехват отметок «прочитано» (MAIN-мир)
    ├── vk-stealth-bridge.js   мост настроек для невидимки
    ├── gpt-hook.js            «Сигнал»: начало/конец потока ответа ChatGPT (MAIN-мир)
    ├── gpt-sounds.js          «Сигнал»: встроенные звуки (Web Audio)
    └── gpt-signal.js          «Сигнал»: определение конца ответа, галочка на вкладке
```

## v2.0.0 — умный VK st fix

Модуль «VK st fix» переработан по итогам разбора аварии шарда st*-54 (август 2026):

**Перезаписчик URL (content/vk-shard-rewrite.js, MAIN world).** Подменяет адрес битого
шарда на рабочий хост ещё до создания запроса — в момент, когда код ВК формирует URL
чанка. Динамические webpack-модули (просмотрщик фото Photoview, видеоплеер) уходят на
здоровый шард обычным путём, без редиректа, поэтому строгая CORS-загрузка не рвётся.
Настройки (номер шарда / целевой хост / вкл-выкл) подтягиваются через мост
vk-shard-bridge.js: кэш в localStorage + живое обновление событием.

**CORS-пропуск (правило id 1002).** Рабочий хост отдаёт чужие чанки, но не шлёт
Access-Control-Allow-Origin — дописываем заголовки сами (origin https://vk.ru +
credentials), иначе ленивые чанки падают с CORS error при живом файле.

**Сторож (background.js + webRequest).** Слушает сетевые ошибки на доменах ВК
(vk.ru, vk.com, userapi, vkuservideo, mycdn, vk-cdn). Любую пишет в журнал
(до 400 событий, chrome.storage.local). При ошибке сертификата на очередном
st*-*.vk.ru сам добавляет правило редиректа (id 2001+) — если ВК сломает ещё
один шард, он вылечится автоматически. При смене целевого хоста в настройках
правила сторожа пересобираются под новый хост.

**Отчёт (попап, вкладка st fix).** «Скопировать отчёт» — сводка: активные правила,
вылеченные шарды, сгруппированный журнал ошибок с примерами URL. Готовый текст
для тикета в поддержку ВК. «Очистить журнал» — обнуляет копилку.

Редирект-правило (id 1001) сохранено как второй эшелон: покрывает запросы,
которые перезаписчик не видит (вшитые в HTML, из service worker и т.п.).

Прежние правила: как только ВК починит DNS st*-54 (dig +short st1-54.vk.ru
перестанет отдавать sun1-54.userapi.com) — модуль можно выключить тумблером.
