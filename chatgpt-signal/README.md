# Мой сигнал для ChatGPT

Личное расширение для Chrome / Edge / Яндекс Браузера / любого Chromium:
звук (и при желании системное уведомление), когда ChatGPT закончил отвечать.

## Установка

1. Распакуйте архив в **постоянную** папку (после установки её нельзя удалять/перемещать).
2. Откройте `chrome://extensions` (в Edge — `edge://extensions`).
3. Включите **«Режим разработчика»** (справа вверху).
4. Нажмите **«Загрузить распакованное расширение»** и выберите папку `chatgpt-signal`
   (ту, где лежит `manifest.json`).
5. **Обновите вкладку chatgpt.com (F5)** — без этого на уже открытых вкладках не заработает.
6. Нажмите значок пазла → «Мой сигнал для ChatGPT» → закрепите его и нажмите «Проверить звук».
   Если открыть окно на вкладке ChatGPT, вверху будет зелёная строка «Вкладка подключена».

Обновление: замените файлы в той же папке и нажмите ⟳ у расширения на `chrome://extensions`,
затем обновите вкладку ChatGPT.

## Настройки

| Настройка | Что делает |
|---|---|
| Сигнал включён | Главный выключатель |
| Только в фоне | Молчать, если вы и так смотрите на вкладку ChatGPT |
| Уведомление | Всплывающее системное уведомление; клик по нему открывает нужную вкладку |
| Звук | 5 встроенных звуков или **свой файл** (mp3/wav/ogg до 3 МБ) |
| Громкость | Громкость сигнала |

## Как это работает (и почему прошлая версия молчала)

Прошлая версия искала только кнопку «Стоп» по её `data-testid`/подписи/SVG-иконке.
ChatGPT часто меняет вёрстку — селектор переставал совпадать, и расширение просто
не видело, что ответ вообще шёл.

Теперь два независимых признака:

1. **Сетевой поток ответа** (`page-hook.js`). ChatGPT присылает ответ потоком
   `text/event-stream` на адрес `…/backend-api/…conversation`. Расширение замечает
   начало и конец этого потока. Это не зависит от вёрстки.
2. **Кнопка «Остановить»** у поля ввода (`content.js`) — запасной вариант.

Ответ считается готовым, когда оба признака «затихли» на 1,5 с. Если поток оборван
(вы нажали «Стоп» или ушли в другой чат) — сигнала нет.

Звук играет в скрытом offscreen-документе расширения (`offscreen.js`), поэтому
работает, даже когда вкладка ChatGPT в фоне или в другом окне.

## Приватность

- Текст переписки и поля ввода не читается: у потока ответа проверяется только
  тип и момент окончания, сами данные сразу отбрасываются.
- Никаких запросов в интернет и аналитики (`connect-src 'none'`).
- Настройки и свой звуковой файл хранятся локально в браузере.

## Если не работает

- **«Проверить звук» молчит** — проверьте громкость системы и что сайт/браузер не заглушён
  (в микшере громкости Windows есть отдельный ползунок для Chrome).
- **Проверка звучит, а после ответа тишина** — обновите вкладку ChatGPT (F5).
  На `chrome://extensions` → «Подробнее» → «Просмотреть: service worker» можно
  посмотреть ошибки в консоли.
- Браузер может «усыпить» давно неактивную вкладку — тогда сигнал придёт, когда вы её откроете.
